The shift

Two Waves of LLMs in Biology

First wave: information retrieval

  • Summarising papers, answering pathway questions, extracting structured data from text.
  • Useful but incremental.

Second wave: autonomous execution

  • Modern LLMs can write, debug, and execute code.
  • Connected to file systems, databases, and command-line tools, they plan multi-step analyses and adapt on intermediate results.
The first wave was chat over the literature. The second wave is agents that actually run the analysis. When the agent does the work, the researcher's job shifts from producing code to evaluating output. That shift is the whole talk.
Definition

Defining Agentic Genomics

An AI agent that plans and executes a genomic analysis end to end: it reads the data, chooses the tools, runs them, inspects intermediate results, and revises its own plan, with a human evaluating rather than typing every command.

Senses

Reads VCFs, FASTQs, manifests, guidelines, and prior outputs as context.

Acts

Invokes real tools: aligners, variant callers, annotation and reporting skills.

Adapts

Checks intermediate results and re-plans, instead of running a fixed script.

Grounded in the Corpas, Fatumo & Guio Perspective on agentic genomics, and a Briefings in Bioinformatics benchmark of frontier LLMs in pharmacogenomics.

Keep the definition concrete: sense, act, adapt. The novelty over a pipeline is the adaptation loop and the human moving to an evaluator role. Cite the Perspective and the benchmark so people know this is grounded, not hype.
The paradigm shift

The work moves from code production to validation

Generating the analysis is no longer the hard part. Knowing you can trust it is.

This is the hinge slide. The cost of producing an analysis collapsed. The cost of validating it did not. Old failures crashed; new failures pass silently. That is what makes this domain different from ordinary coding.
The new bottleneck

The Validation Bottleneck: silent, plausible-looking failure

Plausible

The output is formatted correctly, reads fluently, and matches what a reviewer expects to see.

Confident

The agent states a wrong answer with the same tone as a right one. No flag, no uncertainty.

Consequential

In genomics the failure mode is a missed cancer gene or a wrong dose, not a 404. And it scales.

A healthy 32-year-old's exome is screened. The agent calls a pathogenic BRCA1 frameshift "likely benign" — clean report, a citation, no flag raised. She is never offered screening or risk-reducing surgery. The first sign is stage IV cancer.

Nothing crashed. Now run that same pipeline across 10,000 genomes overnight.

A confident, plausible, wrong answer is worse than no answer. Safe uncertainty beats confident hallucination.

Make the stakes visceral. A silent BRCA1 misclassification is irreversible and the consequence is a preventable cancer death, not a typo. The agentic twist: a human reviewer would catch one crash; an agent industrialises the silent error across thousands of genomes before anyone looks. The goal of the architecture is to abstain or stay correct rather than confidently hallucinate.

Empirical question

Can a plain-text SKILL.md reach clinical-grade?

Pharmacogenomics, ground truth from CPIC guidelines, 44,550 scored evaluations across frontier models and three conditions: free prompt, the skill's reasoning, and executing the skill.

80.6%
Free prompt
(no specification)
95.5%
Skill reasoning
(guideline loaded)
100%
Skill execution
(deterministic)

Accuracy climbs as correctness is constrained by architecture, not by asking the model more nicely.

The headline result. Free-prompt accuracy is good but not safe. Loading the guideline helps. Only executing the skill, where the mapping is deterministic and auditable, hits 100% and is model-invariant. Trust lives in the architecture, not the model.
The counterintuitive result

Giving the model the right guideline made it more dangerous

Trust is architectural: it comes from deterministic, auditable, model-invariant execution, not from a better prompt.

The non-obvious finding people remember. Adding the right guideline as free context is not the same as enforcing it. Only constraining the mapping makes it reliable. This is the argument for skills as contracts.
And it is not equal

On real genomes, accuracy falls by ancestry

Curated ~96% does not transfer to real diplotypes from over 7,000 individuals. Executing the skill removes the gradient. Validation is also an equity problem.

The challenge that should stay with the audience. Benchmark accuracy on curated cases hides a steep drop on real, diverse genomes, and the drop is worst for under-represented ancestries. Architecture that enforces the mapping closes the gap. This is why open, validated skills matter.
