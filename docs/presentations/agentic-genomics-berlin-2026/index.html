The shift

Two waves of LLMs in biology

FIRST WAVE

Information retrieval · chat · summarisation

Useful, but incremental.

SECOND WAVE

Autonomous execution · multi-step planning · tool use

Writes, debugs and runs code. Plans. Recovers from failure.

Bottleneck: producing code → validation and judgement

The researcher moves from producer to evaluator. That is the whole talk.

64 per cent of this room uses coding agents daily. You already live in the second wave. The question is what happens to your job when the code stops being the hard part.
Definition

What makes a system agentic

1

Autonomy. Run-time decisions, not a static workflow.

2

Domain constraint. A structured library of validated skills, not ad hoc code.

3

Iterative refinement. Reads intermediate results, recovers from error.

4

Natural-language mediation. You describe intent; the agent translates it to execution.

Jointly necessary, and falsifiable by the perturbation test: an agent that ignores a corrupted intermediate output was never agentic.

The perturbation test is worth stealing for your demo today. Break an intermediate output on purpose and see whether the agent notices. If it does not, you have a pipeline with a chat interface.

Framework

Validation proportional to consequence

RESEARCH GRADE

Hypothesis exploration. Unit tests, adversarial inputs, every output reviewed. False positives tolerable.

BENCHMARKED

Publishable analyses. Public references (GIAB, GeT-RM), independent benchmarking, published failure modes.

CLINICAL GRADE

Patient care. Multi-centre external validation, signed reproducibility packages, CLIA/CAP.

Today you are building at tier one. Knowing which tier you are at is the skill.

Nobody is shipping clinical-grade software by six o'clock. But a demo that knows which tier it is at, and says so, beats one that quietly implies the top tier.

The empirical question

Can a plain-text skill specification reach clinical grade?

Domain: pharmacogenomics. Genotype → phenotype → drug recommendation, with ground truth fixed by CPIC guidelines.

The risk is real. DPYD rs3918290 T/T plus standard fluorouracil can kill the patient.

Recommendation accuracy, 2,640 evaluations per configuration.

The jump comes from authoring the decision logic, not from which model applies it. Execution adds determinism, auditability and abstention, not accuracy.

Careful with this one: the data do not support execution beating generation on accuracy when both use authored rules. What execution buys is that it is the same answer every time and you can audit it.
Result 2 · the uncomfortable one

Retrieval made it less safe

Lethal-class errors, of 336 attempted per configuration. Free 54 → RAG 137 → authored rules 23 to 26.

Handing the model the guideline text raised phenotype accuracy and raised lethal errors from 54 to 137. 74 of the 83 extra errors are on HLA loci; HLA-B*15:02 goes from 0 of 48 to 45 of 48.

This is the result I would most like you to remember. Retrieval is the thing everyone reaches for. Here it was least safe exactly where the stakes were highest. Scoped finding, fourteen lethal cases, five HLA, wide intervals, not a claim about RAG in general.
Result 3 · and the one that should worry you

Curated accuracy does not transfer to real genomes

96.4% on the curated benchmark · 68.2% family WGS (n=4) · 60.6% Iberian (n=93) · 53.4% Latin American (Peru) · 37.2% East African (Uganda)

Same skill, same models. The benchmark was the easy part. Whose genome does this fail? is not a rhetorical question.

Uganda cohort is 6,407 individuals, Peru 736. This is Challenge 3, and it is not hypothetical: a published, benchmarked, 96 per cent skill is at 37 per cent on East African genomes. If a team goes near this today I will be very happy.
Result 4

Two ways to be useless

THE DETERMINISTIC MAPPING

Never wrong. Often silent.

Answers only where its vocabulary contains the called diplotype. Correct on every answer it emitted, in all four cohorts.

THE AGENT

Answers almost everything. Wrong on 21 to 41 per cent of it.

Declines on 13.5% to 37.2% of states, and the rate of clinically wrong answers shows no cohort ordering at all.

A confident wrong answer is worse than an honest refusal.

This is the judging criterion today: claims that cannot be checked do not count.

Say this one slowly. Every team will build something that answers. The teams worth voting for will be able to show you the question it refused, and why.
Result 5 · practical

Give the model the definitions, and pick your model

Supplying the caller's allele-definition table moved the best model from 39.6% to 96.7% against the caller. Eight models holding the same table span 46.4% to 81.4% against external consensus (GeT-RM), n=527 pairs per model.

Structure helps every model. It does not make them equivalent.

Directly useful today: whatever model you pick on Token Factory, giving it the vocabulary matters more than the prompt. And do not assume the biggest model wins; look at what Gemini Flash does on accuracy versus coverage.
The thesis

Validated skills are necessary and not sufficient

Authoring the decision logic moves recommendation accuracy from 62.4% to 97.0%. Executing it adds determinism, bounded failure and explicit abstention.

And it still reaches only 37.2% on East African genomes, still inherits every error in the input call, and still echoes a corrupted contract: 88 of 90 responses followed deliberately corrupted rules, none reverted to the correct answer.

Corpas, Iacoangeli, Bourdenx, Aldraimli, Jabalameli, Skene, Guio, Fatumo. Cell Genomics, in revision, 2026 · Zenodo 10.5281/zenodo.21905387 · tag agentic-pgx-benchmark-v2.3

The supply-chain result is the one to leave them with. If someone tampers with the skill, the model does not save you. It faithfully executes the wrong thing. That is an argument for signing and auditing skills, which is the next piece of work.
Today

What this means for what you build by five

CHALLENGE 1

End the diagnostic odyssey. Ranked shortlist with the evidence visible, and an explicit list of variants you were not entitled to rank.

CHALLENGE 2

A cancer target you would defend. The case against as visible as the case for. An unresolvable PMID puts you out of contention.

CHALLENGE 3

Whose genome does this fail? Find where a score stops meaning anything, then build the agent that declines to report it.

Judged on four things: does it run, would you trust it, is it reusable, did it need agents.

A confident answer with an invented source scores below an honest abstention.

Bring your own question is fine too, we scope it at 13:05. Public data, and being wrong has to matter.
